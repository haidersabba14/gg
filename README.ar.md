# GG Customizer

**آيفونك. أسلوبك. قواعدك.**

GG Customizer هو استوديو SwiftUI محلي يركز على الخصوصية لإنشاء حزم أيقونات
وخلفيات ولوحات ألوان وثيمات ومعاينات للشاشة الرئيسية وويدجتات وأنشطة مباشرة
بتصميم فاخر. لا يحتوي على إعلانات أو اشتراكات أو SDK للتتبع أو خادم مطلوب.

[English README](README.md) · [التثبيت](docs/INSTALLATION.md) · [حدود الإمكانات](docs/CAPABILITIES.md)

## ما الذي ينفّذه الإصدار الأول فعليًا؟

- استيراد PNG وWebP وإنشاء أيقونات قابلة للتصدير مع تأثيرات محلية وأشكال وظلال
  وانعكاسات وتحكم بالحجم، مع إزالة خلفية محلية اختيارية حين يدعمها iOS.
- حفظ حزم الثيمات والمفضلة والتقييمات وسجل التراجع والنسخ الاحتياطية وتقارير
  الاستعادة داخل الجهاز، مع استيراد وتصدير محليين.
- تضمين 20 ثيمًا مجانيًا ومحرك ألوان ذكي محلي ومولد ثيمات عشوائي. زر التطبيق
  يغيّر GG Customizer وويدجتاته المدعومة فقط.
- محررا Passcode وDialer تفاعليان للمعاينة والتصدير فقط؛ لا يطلب التطبيق رمز
  مرور الجهاز ولا يقرأه ولا يخزنه.
- معاينات متعددة الصفحات للشاشة الرئيسية وشاشة القفل، وتصدير خلفيات مع تعليمات
  iOS الرسمية لتطبيقها يدويًا.
- Live Activities لمهام GG Customizer على الأجهزة المناسبة، وتحكم اختياري في
  مركز التحكم على الإصدارات المدعومة.
- مركز توافق يوضح حالة كل ميزة، ومركز استعادة طارئ يتعامل مع ملفات وإعدادات
  GG Customizer داخل صندوقه فقط.

## حدود iOS التي نلتزم بها

لا يقوم المشروع بعمل jailbreak ولا يستخدم APIs خاصة ولا يعدل ملفات SpringBoard
ولا يستخدم الاختصارات كبديل مخفي لتغيير الأيقونات.

لا تسمح Apple لتطبيق عادي بتغيير الأيقونات الأصلية لتطبيقات أخرى، أو عرض قائمة
كل التطبيقات المثبتة، أو تعديل لوحة رمز القفل، أو تحريك أيقونات الشاشة الرئيسية،
أو تعيين خلفية النظام برمجيًا، أو إعادة تصميم Dynamic Island أو تطبيق الهاتف أو
عناصر مركز التحكم الأصلية. لذلك يسمي GG Customizer هذه العمليات **معاينة** أو
**تصدير** أو **غير مدعومة** بوضوح ولا يدّعي تطبيقها على النظام.

للتفاصيل راجع [docs/CAPABILITIES.md](docs/CAPABILITIES.md).

## المتطلبات

- macOS مع Xcode 16 أو أحدث. الحد الأدنى للمشروع iOS 17، وتُستخدم APIs الأحدث
  فقط بعد فحص التوفر وقت التشغيل.
- iPhone أو iPad يعمل بـ iOS 17 أو أحدث للميزات الأساسية.
- جهاز يدعم Dynamic Island لعرض النشاط في الجزيرة.
- iOS 18 أو أحدث لتحكم مركز التحكم الاختياري.
- هوية توقيع Apple وProvisioning Profile مناسبين لتثبيت التطبيق على جهاز فعلي.
  لا تُرفع أي شهادة أو مفتاح أو كلمة مرور إلى هذا المستودع.

لا يُعلن عن اختبار أي إصدار iOS مستقبلي لمجرد أن رقم الإصدار أعلى؛ يفحص التطبيق
الإصدار والقدرات في وقت التشغيل.

## البناء والاختبار

افتح `GGCustomizer.xcodeproj` في Xcode، واختر scheme باسم `GGCustomizer`، ثم
شغّل اختبارات الوحدة على محاكي iOS. مثال سطر الأوامر موجود في
[README الإنجليزية](README.md#build-and-test).

تشغّل GitHub Actions اختبارات محاكي غير موقعة عند كل push وpull request. يوجد
workflow يدوي منفصل لإنتاج IPA موقّع فقط بعد إضافة أسرار التوقيع إلى GitHub؛ راجع
[تعليمات التثبيت](docs/INSTALLATION.md).

## الخصوصية

- تبقى الثيمات والنسخ الاحتياطية والمعاينات والملف المحلي داخل حاوية التطبيق ما
  لم يختَر المستخدم مشاركتها أو تصديرها.
- تستخدم الصور المستوردة لعملية التصميم التي يطلبها المستخدم فقط.
- لا يطلب التطبيق صلاحيات الصور أو الموقع أو التقويم أو الإشعارات إلا عند تفعيل
  الميزة ذات الصلة.
- لا يجمع التطبيق Apple ID أو رمز المرور أو UDID أو IMEI أو الرقم التسلسلي أو
  معرّف تتبع.

## سياسة التوقيع

لا ترفع شهادات Apple أو provisioning profiles أو المفاتيح الخاصة أو كلمات المرور
أو ملفات `p12` إلى Git. يستقبل workflow الـ IPA الموقّع مواد التوقيع مؤقتًا من
GitHub Actions Secrets ثم يحذفها عند انتهاء المهمة.
